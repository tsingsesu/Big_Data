## 2．增加模型假设及可识别性边界

**原文位置**：02_preprocess.tex“感官数据方面……”以及本节末尾“正确做法是……有序校准”。

**问题**：无标签不能靠校准恢复绝对量表；逐品评员标准化后聚合不保证与原始均分排序相同。把复杂模型写成必然正确，超出证据。

**整体替换该部分感官量表解释，并增加以下假设段：**

```latex
本文的监督对象为附件提供的标准化聚合感官响应，记为$y_{i,s}$；相对报告等级记为$k_{i,s}$，两者不混用。若观测值满足$y=(k-a)/b$，即使$b>0$，未知中心$a$和尺度$b$仍使绝对档位无法由$y$唯一确定。若评分先按不同品评员各自缩放、再聚合，原始均分的排序也不必严格保留。因此本文不把标准化响应反变换为原始人工评分；0--6输出仅是明确训练折锚点下的报告尺度。

模型采用以下工作假设。第一，样本在既有商业啤酒与风格构成范围内可用于评估同类新样本，但不外推到未观测工艺或新风格。第二，MCAR及由可观测酒精度驱动的MAR只作为压力测试情景，不能验证自然缺失机制；未检出可能与低浓度有关，本文缺少检测限元数据。第三，化合物相关图仅表达观测关联，不能判定直接反应或因果方向。第四，生成模型的高斯依赖与协方差收缩是小样本正则化假设，不是对真实酿造分布的确认。第五，迁移的化学约束不等价于整体感官缺陷或实际工艺可行性保证。
```

## 3．变换核验：纠正“161列已判定log10”和精确反演

**原文位置**：02_preprocess.tex“数据概况与表间对齐”的变换段、表“逐列变换核对结果”，以及“变换、标准化与特征构造”的第一段。

**问题**：未校准列的底数不可凭值域确认；校准零值不能由10的幂精确反演；X4VG应放在校准log10组。pH在本附件确有log10数值关系，与题目概括存在冲突。

**以上变换说明及原表整体替换为：**

```latex
以附件8.xlsx的校准表为参照，对每个公共特征分别比较线性、$10^x$及$e^x$三种候选在正校准值上的中位相对误差。70个公共列中，37列支持log10关系，33列支持线性关系；另外161列没有校准依据，标为底数未确认，不因负值或小值域而执行浓度反演。完整误差、校准零数与零值反演不一致数随支撑材料提供。

\begin{table}[htbp]
\centering
\caption{逐列尺度核验及使用边界}
\label{tab:transform-summary}
\begin{tabular}{lrl}
\toprule
类别 & 列数 & 典型列与限制\\
\midrule
正值区间支持log10 &37&DMS、ethyl acetate、X4VG、pH\\
支持线性 &33&diacetyl、linalool、geraniol\\
底数未确认 &161&不作浓度反演；保留附件原数值\\

\end{tabular}
\end{table}

其中X4VG校准表有168个零，而对应原表数值反变换约为0.00970，并不等于零，说明零值或低值处理还包含未给出的规则。pH列的原数值与校准pH满足log10关系，本文按实测核验结果处理，并说明与题面“pH保留原量纲”的概述存在差异。浓度约束直接使用校准表，避免从混合尺度的主特征表统一反演。
```

## 4．不同问题使用不同预处理，删除未执行的实验

**原文位置**：02_preprocess.tex“缺失值与异常值处理”“变换、标准化与特征构造”“预处理流程与复现”。

**处理**：删除CLR敏感性、六组合成特征、插补方法敏感性、掩码损失及统一分层划分的已完成叙述。这些不在本轮实现中。保留beer对齐及原始数据只读的说明。原预处理算法可由以下正文替换，避免算法与代码两套口径。

```latex
预处理按任务分别拟合。问题一在每个内层和外层训练集内做中位数插补与分位数正态化，缺失指示仅作为独立消融，且固定为全部231列的观测指示。问题二在每次重采样中重新插补、缩放，并在弹性网选参的内部折中重新拟合插补与标准化。问题三在每个风格留出的训练部分拟合浓度尺度、协方差、经验边际和分位数上限，留出样本不参与这些估计。

问题三对校准浓度中的负值作非负截断，并记录这一处理。令$c_{i,j}$为清理后的浓度，$a_j$为训练集该列正值中位数，以\[
\ell_{i,j}=\log(1+c_{i,j}/a_j),\qquad
z_{i,j}=(\ell_{i,j}-\mu_j)/\sigma_j
\]
构造无量纲特征；$\mu_j,\sigma_j$只由训练集估计，正值全缺失的列使用预设回退尺度。该处理不把pH等理化指标解释成物质浓度，也不假设不同量纲列可任意互换。所有正则化和距离的含义均限于所声明的特征空间。
```

## 5．T2N单位与阈值的语义

**原文位置**：05_q3.tex末尾“若按标注单位，全部远低于检测限”；全文所有“安全值”“绝对安全”“成品放行”。

**整体替换单位解释；有关安全/放行用语删除：**

```latex
反式-2-壬烯醛在附件中标为mg/L，但既有解释曾按$\mu$g/L使用，当前没有足够的一手校准证据确认哪处有误。由于$0.10\,\mu\mathrm{g/L}=0.00010\,\mathrm{mg/L}$，不能因数值看似更合理而选择单位。本文以保留附件标注、上限数值0.00010为主情景，另报告将该列解释为$\mu$g/L、上限数值0.10的替代情景。生成分布不因解释变化而重新选择，约束和超阈值评价分别计算。

本文采用的是研究情景下的感官约束。觉察阈值并非法规限值或食品安全标准，本文结果不能用于成品放行。单位未决情况下，绝对超阈值结论亦保留条件性。
```

## 6．外部数据：替换为实际使用方式

**原文位置**：02_preprocess.tex“外部数据与补充信息”整节；01_problem.tex数据用途表中的相关表述。

```latex
题目推荐的Kaggle啤酒数据在本地取得5,558行、112个风格的词频记录。按互斥语义规则，将其中96个原风格映射到附件22类，映射覆盖4,760行（85.6%）。11列词频按每行总词频归一化；剔除总词频小于50的行后，映射范围内保留4,492行，按风格聚合为22个感官词频原型。映射规则、原型构造和过滤均由同一脚本执行，不依赖手工填入的原型表。
```
