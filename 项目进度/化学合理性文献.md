# 化学/感官合理性文献参考（Q2 / Q3）

> **最后更新**：2026-10-24
> **用途**：为 Q2「每个感官维度的 Top-3 关键化合物」提供化学合理性判据，为 Q3「风格条件生成 + 缺陷化合物不恶化」提供阈值与风格基线。
> **数据源**：`附件/8.xlsx` 的 `Sensory thresholds`、`Sensory names` 两个 sheet；Schreurs et al. (2024) 的 Zenodo 补充材料（`Supplementary Table S1`）；公开文献与 BJCP 2021 风格指南。
> **阅读约定**：
> - `[附件]` = 直接来自 `附件/8.xlsx` 或本数据集补充材料；`[外部]` = 公开文献/风格指南。
> - **阈值是「觉察阈值」（detection threshold），不是法规上限、安全限值或风格目标值。** 对缺陷化合物才把它当上限约束；对酯类、高级醇、萜类等风格正向化合物，阈值只用于计算 OAV（浓度/阈值）判断感官相关性。
> - `8.xlsx` 的 `origin_paper` 列是**化合物来源**（Yeast/Hops/Malt/Wild flora/Others），**不是阈值文献出处**；阈值文献见第 7 节。
> - **OAV（Odor Activity Value）= 浓度 / 阈值**；OAV≈1 表示刚好达到觉察阈值，>1 表示可能被感知，<0.1 通常只能作家族标记。
> - 本数据集来自 Schreurs et al. (2024, *Nature Communications* 15:2368)，`8.xlsx` 作者元数据为 Michiel Schreurs；数据与补充材料见 Zenodo 10653704。

## 0. 一页结论（Q2/Q3 直接可用）

1. **题面点名的 5 个缺陷项中，附件只给了 3 个化合物的数值阈值**：DMS `17.25/19 µg/L`、Diacetyl `0.299/0.09 mg/L`、4VG `0.206/0.2 mg/L`（均值/中位数）；**trans-2-nonenal 行存在但阈值为 NA**；**Stale hops 根本不是化合物**，只出现在 `Sensory names` 的感官属性里（`stale_hops`，Taste/Others），附件没有它的阈值。
2. **外部文献补齐 T2N**：trans-2-nonenal 的啤酒阈值约 `0.03–0.11 µg/L`，常用 `0.1 µg/L`（cardboard/papery）。见第 2 节。
3. **Q3 不能对全表统一 `10^x`**：`1.csv` 是混合尺度。`Calibrated chemical dataset` 共 73 列（3 个标识列 + 70 个化合物列）；70 个化合物列中 **37 列在 `1.csv` 里是 log10、33 列是线性浓度**。Q3 的浓度约束必须用 `Calibrated chemical dataset`（已是线性浓度），或逐列按本文附录 A 的规则换算。
4. **T2N 列的单位与阈值表标注不一致**：阈值表写 `mg/L`，但校准数据中 T2N 中位数约 `0.012`、范围约 `6e-5–15`，按数值范围判断更像 `µg/L`；若按 `mg/L` 解释，99% 的市售啤酒都「超阈值」，不合理。Q3 使用前必须与出题方/原始论文核对（本文按 `µg/L` 做示例计算）。
5. **Q3 推荐「绝对阈值 + 风格基线」双约束**：Pils/Lager 用严格阈值；Tripel/Kriek/Lambic 的 DMS/Diacetyl 风格基线本身高于附件阈值，硬压到阈值会把风格生成得「不像该风格」。建议硬上限取 `max(阈值, 该风格 p75)`，并在论文中同时报告绝对超阈值率。
6. **Q2 合理性四判据**：化学类别匹配 + 来源匹配 + 剂量（OAV≈1 或家族加和）+ 风格分布/共表达支持；四者至少满足三条，才把该化合物列为「化学合理」的 Top-3。

## 1. 附件阈值表（`8.xlsx` → `Sensory thresholds`）

### 1.1 表结构与读法

- 工作表共 **262 行 × 11 列**（1 行表头 + 261 个化合物/指标），其中 **43 行有数值阈值**；其余为 `NA`（多为半定量、无标样或没有可靠阈值）。
- 列含义：
  - `field_name_python`：与 `1.csv` 化合物列大致对应的字段名（部分用空格，需按附录 A 映射）。
  - `chemical_name` / `chemical_name_short`：化合物名。
  - `calibrated`：是否做过校准（`yes` / `yes_gcms` / 空），**不是**阈值来源。
  - `origin_paper`：化合物在酿造中的来源（Yeast/Hops/Malt/Wild flora/Others/Spices/Internal standard）。
  - `unit`：阈值单位。
  - `aging`：陈化过程中的变化方向（`increase` / `decrease` / 空）。
  - `off_flavors`：附件给出的异味描述（只有少数行有）。
  - `threshold_mean` / `threshold_median`：文献阈值的均值/中位数（附件汇总值，非单一来源）。
- 交叉核对：Schreurs et al. 的 `Supplementary Table S1` 有 **235 个化合物**的 `Compound class / Origin / Flavor / Flavor reference`，其感官描述主要引自 **ASBC Beer Flavor Database**（部分来自 ASBC Hop Flavor Database、The Good Scents Company）。本文的「感官描述」优先用 Table S1 的英文描述，附件 `off_flavors` 有值时并列。

## 2. 外部文献交叉核对

### 2.1 关键阈值对照

> 外部阈值受基质（水/啤酒）、定义（odor vs flavor vs recognition）、panel 和温度影响，2–5 倍差异是正常的；下表只用于「数量级核对 + 敏感性分析」，论文主表建议以附件值为准并注明外部对照。

| 化合物 | 附件均值/中位数 | 外部文献阈值 | 外部典型浓度/备注 | 差异解释 | 来源 |
|---|---|---|---|---|---|
| DMS | 17.25 / 19 µg/L | 约 30–45 µg/L | 拉格 15–150 µg/L，艾尔 1–20 µg/L；cooked sweet corn | 附件值偏低，可能汇总了更敏感的面板/不同基质；用附件值会判更多样本「超阈值」 | Anness & Bamforth 1982；Meilgaard 1975 |

### 2.2 外部文献给出的「典型浓度」与「风格关联」

- **DMS**：拉格通常 15–150 µg/L，艾尔 1–20 µg/L；低于约 30 µg/L 时更多是「玉米甜香」，高于 100 µg/L 可能变成「煮蔬菜/烂蔬菜」。DMS 的前体是麦芽中的 S-甲基蛋氨酸（SMM）和 DMSO，也有细菌来源；因此 `origin_paper` 写 Malt 只覆盖了主要来源，Table S1 写 Bacteria, Aging 更完整。
- **Diacetyl**：主发酵后的 VDK，酵母还原不彻底时残留；阈值约 0.1 mg/L，成品啤酒通常控制在 0.1 mg/L 以下。它是 Q3 最需要「不恶化」的缺陷之一。
- **4VG**：酵母 Pad1 酶对阿魏酸脱羧生成；小麦啤中 0.2 mg/L 是风味阈值，0.4 mg/L 是金色特种啤酒阈值；在 Tripel/Pils/Kriek/Lambic 中通常应接近 0，只有在小麦/某些比利时风格中才是正向的 clove 香。
- **T2N**：亚油酸氧化产物，cardboard/papery；0.03–0.11 µg/L 即可察觉，是啤酒老化最经典的标志之一。附件没有给阈值，Q3 必须外部补。
- **酯类/高级醇**：酵母代谢产物；酯类由醇与酰基-CoA 在醇乙酰转移酶/酯酶作用下生成；高级醇经 Ehrlich 途径由氨基酸分解生成。两者在数据集中高度相关（Schreurs et al. 正文：Spearman >0.5），说明它们更适合作为「酵母代谢模块」共同解释，而不是孤立看单个化合物。
- **萜类**：酒花来源为主，linalool/geraniol/citronellol 是柑橘/花香/玫瑰的核心；它们之间存在协同（Takoi et al. 2010：geraniol 与 β-citronellol 在过量 linalool 共存时产生协同柑橘香）。Q2 的「Hops - citrus」维度可以把它们作为一组，而不是只取一个。
- **Stale hops（陈旧酒花）**：不是单一化合物。外部研究把 aged hops 的异味归因于支链脂肪酸（isobutyric acid、isovaleric acid、2-methylbutyric acid）的 cheesy/sweaty/rancid 气味；低剂量 aged hops 反而能增强 fruity/fullness/maturity。附件 `5.csv` 中 `Stale hops` 与 `Barnyard` 的相关高达 **0.97**，与 `DMS` **0.25**、`Trans-2-nonenal` **0.24**；`6.csv` 中与 `Ethyl 2-methylbutyrate` **0.203**、`Ethyl 3-methylbutyrate` **0.167** 正相关。结论：它是一个「陈旧酒花/野生感」复合轴，Q3 只能用代理变量或感官评分约束。

## 4. 感官维度 → 候选化合物对照表（Q2）

### 4.1 使用规则

对每个感官维度，先按下面四步筛「化学合理」的 Top-3：

1. **类别匹配**：化合物类别与维度语义一致（酯香→酯类；酒花→萜类/异 α-酸；麦芽→醛/吡嗪；野生→酸/酚）。
2. **来源匹配**：`origin_paper` 与维度来源一致（Yeast/Hops/Malt/Wild flora/Others）。
3. **剂量匹配**：用 `Calibrated chemical dataset` 算 `OAV = C / threshold`；OAV≥1 为强证据，0.1–1 为弱证据，<0.1 只能作家族标记/协同解释。**OAV 只用 70 个校准化合物列**；不在其中的列（如 `X4.ethyl.phenol`、`benzaldehyde`）只能做相关/相对比较，不能算绝对 OAV。
4. **风格/共表达匹配**：该化合物在目标风格中的分布与维度一致；且在 `2.csv` 中与同族化合物正相关、在 `6.csv` 中与目标感官正相关。

> 说明：`2.csv` 是化合物-化合物相关矩阵，`6.csv` 是 44 个化合物/指标 × 50 个感官属性的交叉相关矩阵；`6.csv` 的相关整体偏弱（|r| 多在 0.1–0.3），只能作辅助证据，不能单独定 Top-3。

### 4.5 复合维度与派生列

- `esters_sum`、`aroma_hops_sum`、`acids_sum`、`sulfur_sum` 是附件中由多个化合物计算出的派生属性（赛题原文也说明「五个属性由多个单独测量的化合物计算得出」）。它们对「总体/家族」维度化学合理，但**不是单个化合物**；如果 Q2 的 Top-3 出现这些列，论文里要注明「派生指标，非单一化合物」。
- 对 `A_esters_all`、`F_esters_all`、`A_hops_all`、`F_hops_all` 这类「overall」维度，Top-3 很可能是家族内多个化合物 + 一个派生总和；这比硬凑三个不相关化合物更化学合理。

## 5. 四个风格的轮廓与附件实证

> 风格描述来自 BJCP 2021；数值来自 `8.xlsx` `Calibrated chemical dataset` 的 250 个样本，按 `tasting_category_fine` 分组。样本量：Tripel 28、Kriek 10、Lambic 11、Pils/Lager 11；小样本的 p75 不稳定，Q3 建议用 bootstrap 或 p50±IQR。

### 5.1 Tripel（BJCP 2021 26C）

- **风格轮廓**：强烈、浅色、带香料感的比利时艾尔；香气复杂，**中等至明显香料感 + 中等果香酯 + 低而柔和的酒精**，酚类呈胡椒/丁香，酯香常为柑橘（橙/柠檬），偶尔熟香蕉；酒花低（可选轻微花香/香料/香水感），麦芽轻。入口干爽，**中等至中高苦度**，酯/酚低至中等，不应甜；**高碳酸化**，酒精感被掩盖。
- **附件实证（n=28，中位数）**：乙醇 `8.76% v/v`、甘油 `2.94 g/L`；酯类高：乙酸乙酯 `38.9 mg/L`、乙酸异戊酯 `4.79 mg/L`、己酸乙酯 `0.351 mg/L`、辛酸乙酯 `0.687 mg/L`、乙酸苯乙酯 `0.310 mg/L`；异戊醇 `50.8 mg/L`、异丁醇 `12.9 mg/L`、苯乙醇 `6.39 mg/L`；萜类高：linalool `0.372 mg/L`、geraniol `0.177 mg/L`、citronellol `0.228 mg/L`、α-terpineol `0.393 mg/L`；4VG 中位数 `0`。
- **判读**：Tripel 的「果香 + 香料 + 柔和酒精」与高酯、高异戊醇、高萜类完全吻合；4VG=0 符合「非酚香型」的比利时酵母。**DMS `37.2 µg/L`、diacetyl `0.290 mg/L` 都在附件阈值附近/之上**，是 Tripel 生成时最需要盯的缺陷风险；不能因为「风格基线高」就忽略。注意 Tripel 的 diacetyl 分布是双峰的（p25≈0.001、p50≈0.290、p75≈0.589），Q3 不要只用 p50 当唯一目标，建议用分位数/混合分布描述。
- **Q3 目标**：Pils→Tripel 迁移时，主要上调乙醇、甘油、乙酸乙酯、乙酸异戊酯、己酸乙酯、辛酸乙酯、异戊醇、linalool、geraniol、citronellol；4VG 保持接近 0；DMS/diacetyl 不超过 Tripel 风格基线或不恶化。

### 5.2 Kriek（BJCP 2021 23F Fruit Lambic，樱桃）

- **风格轮廓**：水果 Lambic；樱桃（酸樱桃/莫雷洛）应主导，带杏仁/果核、石榴、轻微酒香；底层是 Gueuze 的谷仓、干草、皮革、旧木、乳酸酸感与 Brett 野味；传统款干、酸、清爽，带单宁；苦度很低（0–10 IBU）；酒精度 5–7%，碳酸化可高可低。醋酸/醋味不是正面目标。
- **附件实证（n=10，中位数）**：乙醇 `6.36% v/v`、甘油 `2.28 g/L`；乳酸 `2.21 g/L`、醋酸 `0.52 g/L`（远高于附件阈值，是风格正向）；酯类低于 Tripel：乙酸乙酯 `24.4 mg/L`、乙酸异戊酯 `0.316 mg/L`、己酸乙酯 `0.166 mg/L`、辛酸乙酯 `0.238 mg/L`；diacetyl `0.432 mg/L`、DMS `10.8 µg/L`、4VG `0`；linalool `0.356 mg/L`、geraniol `0.136 mg/L`、citronellol `0.046 mg/L`。
- **判读**：高乳酸/醋酸 + 低酯 + 4VG=0 是 Kriek 的化学指纹；diacetyl 中位数偏高，是主要缺陷风险；樱桃的杏仁感可由 `benzaldehyde` 解释（1.csv 有该列，但不在 70 个化合物校准列中，使用时要标注尺度）。
- **Q3 目标**：保留乳酸/醋酸在风格区间（不要「去酸」）；樱桃来源的苯甲醛/果香酯可增强；diacetyl 不超过风格 p75；DMS 不超过 17.25 µg/L；4VG 接近 0。

### 5.3 Lambic（BJCP 2021 23D）

- **风格轮廓**：自发发酵的比利时小麦啤酒；年轻款酸、果香（柑橘、仁果、大黄），陈款出现谷仓、土味、山羊/马毯、干草；**没有酒花香气**，苦度通常低于阈值，酸度提供平衡；干爽，酒精度 5.0–6.5%，高碳酸化；使用 3 年以上陈年酒花，主要起防腐作用而非苦味。
- **附件实证（n=11，中位数）**：乙醇 `6.31% v/v`、甘油 `2.11 g/L`；乳酸 `2.36 g/L`、醋酸 `0.525 g/L`；DMS `21.4 µg/L`、diacetyl `0.247 mg/L`、4VG `0`；乙酸乙酯 `37.1 mg/L`、己酸乙酯 `0.252 mg/L`、辛酸乙酯 `0.534 mg/L`；linalool `0.348 mg/L`，但 **geraniol 仅 `0.0044 mg/L`**、citronellol `0.052 mg/L`；α-terpineol `0.375 mg/L`；humulene `0.022 mg/L`、caryophyllene `0.0038 mg/L`。
- **判读**：高乳酸/醋酸 + 极低 geraniol + 低倍半萜，符合「陈年酒花 + 长时间陈化」；DMS 高于附件阈值但低于外部 30 µg/L，是 Lambic 的复杂硫味的一部分，不一定是缺陷。**注意**：Lambic 虽然使用陈年酒花，但 BJCP 23D 明确「不应有 cheesy 异味」；`stale_hops` 不能简单等同于「风格正向」。Q3 不要把 stale hops 主动增强，只允许它随 Brett/陈年基线存在，并以风格 p75 为上限。
- **Q3 目标**：保留酸度和 Brett 野味；允许 stale hops/aged hops 到风格 p75；4VG 接近 0；diacetyl/DMS 不超过风格 p75；不要用 Pils 的「干净」标准去生成 Lambic。

### 5.4 Pils/Lager（BJCP 2021 5D German Pils）

- **风格轮廓**：干净发酵、麦芽谷物/面团/蜂蜜/烤饼干，酒花花香/香料/草本，中等至中高苦度，干爽清脆；**不应有 diacetyl**，DMS 只能极低；酒花应突出但不压过麦芽。
- **附件实证（n=11，中位数）**：乙醇 `5.19% v/v`、甘油 `1.53 g/L`；DMS `15.1 µg/L`（略低于附件阈值 17.25，远低于外部 30）、diacetyl `0.0417 mg/L`（远低于阈值）、4VG `0`、T2N `0.0020`（按 µg/L）；酯类低：乙酸乙酯 `10.6 mg/L`、乙酸异戊酯 `0.956 mg/L`、己酸乙酯 `0.123 mg/L`、辛酸乙酯 `0.191 mg/L`；高级醇低：异戊醇 `26.6 mg/L`、异丁醇 `5.84 mg/L`、苯乙醇 `8.71 mg/L`；萜类低：linalool `0.0418 mg/L`、geraniol `0.0294 mg/L`、citronellol `0.0630 mg/L`。
- **判读**：这是四个风格中最「干净」的基线，适合作为 Pils→Tripel 迁移的源风格；缺陷预算低（DMS/diacetyl/T2N/4VG 都接近 0），迁移时应保持「不恶化」。
- **Q3 目标**：源风格缺陷上限取 Pils 的 p75（DMS 16.7 µg/L、diacetyl 0.057 mg/L、T2N 0.0034 µg/L）或附件阈值（更宽）；4VG 用 `≤0.10 mg/L` 的安全值（p75=0 只说明中位/上四分位都低于检出，不宜把生成值硬卡到 0）；正向目标取 Tripel 的 p25–p75（见 6.5）。

## 6. Q3 缺陷约束设计（可直接落地）

### 6.1 缺陷项定义与单位

Q3 题面点名：`DMS / Diacetyl / 4VG / trans-2-nonenal / Stale hops 等超阈值项`。其中：

| 缺陷项 | 是否为化合物 | 附件阈值 | 建议使用的浓度列 | 单位 | 备注 |
|---|---|---|---:|---|---|
| DMS | 是 | 17.25 / 19 | `DMS` | µg/L | 附件均值/中位数；外部 30–45 |
| Diacetyl | 是 | 0.299 / 0.09 | `X2.3.butanedione` | mg/L | 严格用 0.09，宽松用 0.15 |
| 4VG | 是 | 0.206 / 0.2 | `X4VG` | mg/L | 非小麦风格接近 0；小麦风格可到 0.4 |
| trans-2-nonenal | 是 | 附件 NA | `X.E..2.nonenal` | µg/L（按数值判断） | 外部 0.1 µg/L；单位需核对 |
| Stale hops | **否** | 附件无 | 无直接列 | — | 用代理变量/感官评分；见 6.4 |

**重要**：`Sensory thresholds` 的 `threshold_mean/median` 是「觉察阈值」，不是「风格上限」。对 DMS/diacetyl 这类缺陷，超阈值通常意味着异味风险；对 4VG，超阈值在小麦啤里是风格正向；对 stale hops，没有化合物阈值，不能硬套。

### 6.2 绝对阈值（严格模式）

若 Q3 只要求「不超阈值」，用下面这组硬上限（全部风格统一）：

```
DMS        ≤ 17.25 µg/L
Diacetyl   ≤ 0.09 mg/L
4VG        ≤ 0.20 mg/L（非小麦风格建议 ≤0.10）
T2N        ≤ 0.10 µg/L
```

优点：解释简单、与题面「超阈值项」直接对应。缺点：Tripel/Kriek/Lambic 的 DMS/diacetyl 中位数本来就接近或超过这些值，严格模式会把风格生成得「过于干净」，损失风格保真度。

### 6.3 风格条件约束（推荐模式）

推荐用「绝对阈值 + 风格基线」双约束：

```
C_j,s ≤ U_j,s = max(T_j, B_j,s^p75)
```

其中 `T_j` 是绝对阈值，`B_j,s^p75` 是风格 s 的真实数据 p75。含义：**既不超过绝对阈值太多，也不超过该风格自己的上四分位**；对风格基线低于阈值的风格，等价于严格阈值；对风格基线高于阈值的风格，允许保留风格特征，但不超过风格自身的 p75。

| 风格 | n | DMS p50/p75 (µg/L) | Diacetyl p50/p75 (mg/L) | 4VG p50/p75 (mg/L) | T2N p50/p75 (µg/L) | 推荐硬上限 U（DMS / Diacetyl / 4VG / T2N） |
|---|---:|---:|---:|---:|---:|---|
| Tripel | 28 | 37.2 / 55.0 | 0.290 / 0.589 | 0 / 0 | 0.0098 / 0.0282 | 55.0 / 0.589 / 0.10 / 0.10 |
| Kriek | 10 | 10.8 / 14.9 | 0.432 / 0.474 | 0 / 0 | 0.0104 / 0.0168 | 17.25 / 0.474 / 0.10 / 0.10 |
| Lambic | 11 | 21.4 / 23.4 | 0.247 / 0.409 | 0 / 0 | 0.0133 / 0.0192 | 23.4 / 0.409 / 0.10 / 0.10 |
| Pils/Lager | 11 | 15.1 / 16.7 | 0.0417 / 0.057 | 0 / 0 | 0.0020 / 0.0034 | 17.25 / 0.09 / 0.10 / 0.10 |

**说明**：
- 4VG 的 p75 在四个风格里都是 0；表中硬上限用 `0.10 mg/L`（非小麦风格的安全值），而不是 `max(T, 0)=0.2`，以避免生成出明显酚味。若生成小麦风格，可放宽到 `0.4 mg/L`。
- T2N 的 p75 都 <0.1 µg/L，所以统一用外部阈值 `0.1 µg/L`。
- Tripel 的 DMS/diacetyl 上限用 p75（55.0 / 0.589），因为其 p50 已接近/超过附件阈值；如果论文要求「严格不超阈值」，请同时报告严格模式的结果作为对照。
- Kriek/Lambic 的 diacetyl p75 也高于 0.09，说明这两个风格的市售样本本身 diacetyl 偏高；Q3 可以选「不超过风格 p75」作为保真约束，或在论文中明确「严格模式会降低风格保真度」。

### 6.4 Stale hops 的代理约束

`Stale hops` 没有化合物阈值，建议用「代理变量组 + 风格基线」而不是发明一个阈值：

**代理组 S（按证据强弱排序）**：

1. `X.E..2.nonenal`（T2N，cardboard/papery；5.csv 与 stale_hops r≈0.24）。
2. `DMS`（硫味/陈化；5.csv r≈0.25）。
3. `X4.ethyl.phenol` + `X4.ethyl.guaiacol`（Brett/野生酚；与 barnyard 同轴；5.csv stale_hops↔barnyard r≈0.97）。
4. `ethyl_2.methyl_butyrate`、`ethyl_isovalerate`（陈年酒花酯；6.csv r≈0.20/0.17）。

**推荐约束**（对 Pils/Tripel 等「不应有陈旧酒花」的风格）：

```
T2N ≤ 0.10 µg/L
DMS ≤ U_DMS,s
4-乙基苯酚 + 4-乙基愈创木酚 ≤ 该风格 p75
ethyl 2-methylbutyrate ≤ 该风格 p75
```

对 Kriek/Lambic（陈年酒花/Brett 是风格的一部分）：允许上述代理到风格 p75，不要主动增强、也不要把 stale hops 硬压到 0；只限制「超过风格上四分位的极端值」。BJCP 23D 仍把 cheesy 异味视为缺陷，所以「允许存在」不等于「鼓励生成」。

> 注意：`X4.ethyl.phenol`、`X4.ethyl.guaiacol` 不在 70 个校准列中，`1.csv` 里的尺度需先按附录 A.3 核对；如果它们是 log10，先换算再和 p75 比较。

**论文写法**：明确写「题面所列 Stale hops 在附件中是感官属性而非化合物；本文用 T2N、DMS、4-乙基酚/4-乙基愈创木酚和 aged-hop 酯作为代理，并以风格 p75 作为不恶化约束」。这样既回应题面，又不虚构阈值。

### 6.6 Q3 评估指标建议

1. **缺陷超阈值率**：对每个生成样本，计算 `1[C_j > T_j]` 的比例；分风格报告。
2. **缺陷最大 OAV**：`max_j (C_j / T_j)`；比单点超阈值更能反映风险。
3. **风格基线距离**：生成分布与真实风格 p25–p75 的覆盖度（如 Wasserstein 距离、KS 统计量），对每个判别性化合物报告。
4. **不恶化率**：`1[C_j,generated ≤ max(T_j, B_j,s^p75)]`；这是 Q3 题面「保持缺陷化合物不恶化」的直接量化。
5. **感官画像一致性**：若生成模型能输出感官维度，计算与真实风格感官中位数的相关性；若不能，用 OAV/代理指标间接评估。
6. **稳定性**：生成模型多次采样（不同 seed）下上述指标的均值±标准差；与 Q2 的 bootstrap 稳定性呼应。

## 附录 B. 未决问题与注意事项

1. **阈值语义**：`8.xlsx` 的阈值是觉察阈值，不是法规上限或风格目标。除题面点名的缺陷项外，不要把阈值当上限（例如 `bitterness` 5 IBU 不是苦度上限，`ethanol` 1.76% 不是酒精度上限）。
2. **T2N 单位**：表内写 `mg/L`，数值范围更像 `µg/L`；Q3 使用前必须核对。本文的 OAV/约束示例按 `µg/L` 解释。
3. **Stale hops 不是化合物**：附件没有它的阈值；只能用代理变量/感官评分。不要把 `stale_hops` 与 `trans-2-nonenal` 画等号（5.csv 相关只有 0.24）。
4. **Diacetyl 均值 vs 中位数**：0.299 vs 0.09 mg/L，差 3 倍；严格约束用 0.09–0.15，风格保真用 p75。论文中要同时报告两种口径。
5. **4VG 风格条件**：Tripel/Pils/Kriek/Lambic 中位数都是 0；小麦/某些比利时风格中 4VG 是正向 clove 香。Q3 不要对小麦风格强制 4VG=0。
6. **小样本**：Kriek n=10、Lambic n=11、Pils n=11，p75 不稳定；Q3 的基线建议用 bootstrap 置信区间或 p50±IQR，不要把小样本 p75 当硬真理。
7. **相关不等于因果**：`6.csv` 的相关整体偏弱（|r| 多在 0.1–0.3），只能作辅助证据；Q2 的 Top-3 仍要以 `2.csv` 共表达 + 多方法稳定性为主，化学合理性作为先验/解释。
8. **派生列**：`esters_sum`、`aroma_hops_sum`、`acids_sum`、`sulfur_sum` 是派生指标；Q2 如果选它们，要注明「派生指标，非单一化合物」。
9. **数据集来源**：本附件是 Schreurs et al. (2024) 的 250 个比利时商业啤酒样本；`8.xlsx` 的 `Calibrated chemical dataset` 与 `1.csv` 的 73 个公共列（3 个标识 + 70 个化合物）对应，但不是所有 `1.csv` 列都有校准值。Q2/Q3 跨列比较时注意这一点。
