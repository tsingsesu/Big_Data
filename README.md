## 运行

在`提交文件夹/支撑材料/`目录、独立Python环境中运行。当前验证环境为Linux、Python 3.10.12，依赖版本见`依赖清单.txt`；准备环境的命令为：

```bash
python3 -m venv ../运行环境
source ../运行环境/bin/activate
python -m pip install -r 依赖清单.txt
```

赛题原始1–8附件不随包重复提交。将下列路径替换为其所在目录；程序只读原始附件：

```bash
export BEER_ATTACHMENT_DIR='/path/to/官方附件'
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1
```

各程序独立执行，默认使用正式实验参数和种子42。完整重算会覆盖结果并产生额外明细，建议在副本中运行。

```bash
python src/01_数据预处理.py
python src/02_外部数据处理.py
python src/问题一_感官评分.py --resume
python src/问题二_化合物关联.py
python src/问题三_风味生成与迁移.py
```

Q1默认3次重复×5折、500棵树；Q2默认500次bootstrap，可通过`Q2_NJOBS`控制并行；Q3默认5次风格内留出，每风格每方案生成300条。Q1/Q2保留中断恢复逻辑，检查点不进Git或最终压缩包。

七图由R/Cairo生成，使用`Noto Serif CJK SC`字体；当前R版本4.6.1。直接用已存绘图数据重绘，无需赛题原始附件：

```bash
Rscript src/论文配图.R . 03,05,17,18,19,20,21
```

重新计算绘图数据时，在三问结果生成后先运行：

```bash
python src/01_数据预处理.py --plots
```

05保留Gephi布局坐标；预处理会核对节点与边，变化时需要设置`GEPHI_HOME`，并提供Gephi 0.11.3、Java 17和javac重算布局。Java源程序中的布局种子为42，迭代1200次。
