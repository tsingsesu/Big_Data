### 4.1 图 3.1 `q1_model_comparison.pdf`

**插在哪**：3.7 节，表 3.1 的说明段之后、`q1_target_r2_heatmap` 之前。
先表后图、先汇总后细化。

**为什么插**：表 3.1 只有三个模型（基线 Ridge、改进、最终融合）。而 3.6 节声明的
对照设置是「逐维均值 → 逐维 Ridge → 多输出 Ridge/PLS2 → 等权融合 → 消融版本」五档
以上，**除三条路线外，PLS、ExtraTrees、RandomForest、LightGBM、Ridge 堆叠、逐维均值
这六个对照的结果在正文里从未出现**。审稿人会问：「五个基学习器各自什么水平？融合
到底比最强单模型好多少？」表 3.1 答不了，本图一次答完。

**论证作用**（读数已核对）：

1. **负的下界**：逐维均值基线 R² = −0.029。完全不看化合物时折外表现低于常数预测，
   这为后续所有改进提供了有意义的下界，也说明 0.227 不是靠平凡模型撑起来的。
2. **单体的强弱排序**：extratrees 0.223 > randomforest 0.217 > ridge 0.162 >
   pls 0.141 > lightgbm 0.137。树模型明显优于线性模型，说明存在线性结构抓不住的
   成分；LightGBM 单体最弱，说明逐目标 boosting 在 N=250 下难以单独收敛。
3. **融合的真实增益**：blend 0.227 相对最强单体 extratrees 0.223 **仅高 0.004**，
   误差棒重叠。单看宏平均 R²，融合并不显著优于最好的单模型。融合的价值在
   **折间标准差更小**与**逐目标更均衡**（见图 3.2）。
4. **堆叠三项近乎打平**：stack_ridge 的 RMSE 0.469 **低于** blend 的 0.470，
   Spearman 0.433 **高于** blend 的 0.432，仅 R²（0.216）落后。三项指标一胜一负一平。
   选等权融合的依据是 R² 为主 + 折间方差 + 3.5 节已说明的堆叠乐观偏置，这一点
   必须在图上被明确指认，不能回避。

### 4.3 图 5.2 `q3_transfer_compounds.pdf`

**插在哪**：5.7 节，替换现有那段「十个数字一句话」，置于表 5.2 之前。

**为什么插**：现有句子是

> 关键化合物均值从 Pils 的乙醇 5.19%、甘油 1.64 g/L、乙酸乙酯 10.8 mg/L、
> 乙酸异戊酯 1.15 mg/L、异戊醇 27.9 mg/L，迁移到 Tripel 的 8.79%、3.11 g/L、

**论证作用**：

1. **缺陷约束不牺牲风味——这是目前缺失的正面结论**。三种变体（raw/strict/style）
   在全部 10 个香气化合物上的柱高**几乎完全重合**，因为缺陷投影只作用于缺陷列。
   这直接回答「压缺陷会不会把香气一起压掉」：不会。这条结论比「缺陷率 = 0」更有
   价值，而现有图 5.4 完全没覆盖。
2. **迁移幅度符合化学预期**：酯类与高级醇温和上升（乙酸乙酯约 3.6 倍、乙酸异戊酯
   约 3.7 倍、乙酸己酯约 2.6 倍、异戊醇约 2.0 倍）；酒花萜类升幅最大（香叶醇约
   4.5 倍、芳樟醇约 18 倍）。与 Tripel 高酒花、高酯的风格特征一致，说明 OT 学到的
   不是无方向的随机位移。
3. **暴露长尾化合物的口径依赖**：芳樟醇柱高 log2 ≈ 4.17（约 18 倍），菱形（Tripel
   均值参照）log2 ≈ 5.58（约 48 倍）。柱低于菱形，说明相对**均值**口径迁移系统性
   偏低；而迁移结果 1.14 mg/L 相对 Tripel **中位数** 0.372 mg/L 是 3 倍过冲。同一
   结果在两种口径下结论相反——这正是正文「后续应以分位数约束取代均值匹配」的依据。

**⚠ 插入前必须核对的 2 处**：

1. **图例文字与实算不符**。图例现写作 `Tripel median / Pils mean`。按正文的 Tripel
   均值 2.97 与 Pils 均值 0.062 计算，比值 47.9（log2 ≈ 5.58），与菱形位置吻合；
   若用 Tripel 中位数 0.372，则仅 6.0（log2 ≈ 2.58）。**已确认分子取均值**，故脚本
   中的图例字符串需改为 `Tripel mean / Pils mean` 后重跑。改的是图例文字，数据不变。
2. **命名统一**。图中 `raw / strict / style` 与 5.5 节正文一致，但表 5.2 与 6.1 用
   「OT+约束」。建议统一为 raw / strict / style，并在首次出现处注明三者对应关系。

**⚠ 配套改动**：见 §5 改动 5、改动 6、改动 7。
